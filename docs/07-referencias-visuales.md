# Referencias humanas reales para mostrar a 7.º

**Objetivo:** que cada equipo debata **una** propuesta de estética. Las páginas de diseño más complejas sirven como inspiración, NO como especificación técnica de la web de los chicos. ## Comparación rápida para el aula

- **Editorial poderoso:** A, D. Para una portada con protagonismo visual.
- **Recuerdos y álbum:** B, C, H, I. Para historia, frases y fotos.
- **Cine y protagonistas:** E. Para galería, créditos y despedida.
- **Retro interactivo:** F, G, J. Para navegación como PC, pero cuidando la simplicidad.
- **Experimental:** K. Para debate sobre qué hace única una web.

## Preguntas que funcionan con 7.º

1. ¿Qué detalle recordarías después de cerrar la web? (No «me gusta porque es linda»).
2. ¿Qué parte podemos llevar a nuestra web de una sola página con pocas fotos?
3. ¿Qué haríamos distinto para que se note que **es nuestro curso**?
4. ¿Funciona esa idea en un celular? ¿Qué dejaríamos afuera?

**Derechos:** no incluir en el anuario material descargado o copiado de estas webs. Las referencias son links educativos, ilustraciones y activos de terceros pertenecen a sus autores.
