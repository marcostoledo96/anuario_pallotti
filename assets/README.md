# Assets

`demo/` contiene gráficos abstractos originales para practicar y probar el lightbox. **No representan ni incluyen alumnos.**

`publicables/` está intencionalmente vacío. El docente incorporará allí únicamente materiales autorizados por la institución para el sitio **público**, sin metadatos EXIF, después de la revisión editorial y de permisos. Nunca copiar aquí originales no aprobados. La carpeta está ignorada por Git inicialmente: solo luego de aprobar cada archivo, el docente debe decidir cómo habilitar su publicación (por ejemplo, ajustar `.gitignore` y agregar únicamente los aprobados).

NO versionar archivos de consentimiento ni fotos sin revisar.
